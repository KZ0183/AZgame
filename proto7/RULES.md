# ふたりの英雄（仮）対応版 ルール v0.5

`proto6`（同時計画制）から、MTG のような**攻守交代＋対応**の形に作り替えた試作。比較のため `proto6` はそのまま残している。
ブラウザで `index.html` を開けば CPU と対戦できる。

## ねらい

- 同時処理だと「計画をまとめて出して結果を見る」だけで、1枚ずつ考える手応えが薄かった
- 相手の攻撃に1枚ずつ「対応」できるようにして、「この攻撃にこのカードで返す」駆け引きを作る

## 構成

| ファイル | 内容 |
| --- | --- |
| `engine.js` | ルールエンジンと CPU。DOM に依存しない（Node でも動く） |
| `index.html` | 画面（タイトル・ヒーロー選択・対戦） |

## 基本

- ヒーローを**2人**選ぶだけでデッキが決まる。各ヒーローは固有のカードを**4枚**持つ
- **カードの巡回**（v0.4。クラッシュロワイヤル方式）
  - 各ヒーローの4枚は**決まった順番で巡回**する。巡回の順番は試合の最初にシャッフルして決まり、相手には見えない
  - 手札は**ヒーローごとに2枚**。カードを使うと列の最後へ回り、列の先頭のカードが**使ったカードと同じ場所に**すぐ入る（1枚ずつ入れ替わる。もう1枚は動かない）。入ってきたカードには自分のターンの終わりまで「NEW」が付く
  - 自分のヒーローには「次に来るカード」が表示される
  - 使ったカードは相手に公開される。**相手が使ったカードを覚えていれば、相手の手札が読める**（履歴は表示しない。記憶の勝負）
  - 倒されても巡回はそのまま続く。手札も失わない
- ヒーローは**前衛**か**後衛**に立つ。前衛向けの攻撃は後衛に届かない（遠距離技は届く）
- お互いの陣地に**タワー**（HP25、v0.4）。**相手のタワーを壊したら勝ち**
  - いつでも狙えるが、持ち主の前衛に誰かいるあいだは、殴ったヒーローに**4ダメージの反撃**。**反撃は1ターンに1回だけ**（v0.3）。一度反撃を受ければ、そのターンは続けて殴れる
  - 前衛が空なら無防備で、反撃はない
- **相手のヒーローを倒すと、相手のタワーにも4ダメージ**（v0.3）
- 10ラウンドで決まらなければ、タワーの残りHP → ヒーローの残りHPで判定

## ターン

- 先攻・後攻はランダム。1ラウンド＝お互いが1ターンずつ
- **自分のターンの始め**に
  - マナが回復する：**ラウンド数+1**（上限6）。最初のラウンドだけ、**先攻は1、後攻は3**（v0.4）
  - 倒れていたヒーローは、**自分のターンを1回休んでから**、次の自分のターンの始めに後衛で全快復活する（v0.2）
  - 自分のヒーローの盾・挑発が切れる
- 自分のターンには、次を**1つずつ**行う（マナが続く限り何回でも）
  - カードを使う（前衛用のカードは、そのヒーローが前衛にいるときだけ。後衛にいるあいだは前衛用のカードが手札に詰まることがある）
  - **固有スキル**を使う（1マナ・1人1ターン1回。v0.5 で通常攻撃の代わりに入れた）
  - **移動**（**無料**・1人1ターン1回、v0.3）：前衛と後衛を入れ替える。復活したヒーローもすぐ前に出られる
- カードも通常攻撃も、**選ぶ →（対象を選ぶ）→「使う」で確定**の1枚ずつの流れ。確定するまでは何も起きず、対象の選び直しや取りやめができる
- 「ターン終了」を押すか、時間切れでターンが終わる（1ターンの時間は30秒・60秒・なしから選べる）

## 固有スキル（v0.5）

巡回するカードとは別に、各ヒーローが毎ターン1回いつでも使える。手札がかみ合わないターンにも、そのヒーローらしい行動が必ず1つある。

| ヒーロー | 固有スキル【1マナ】 | 効果 |
| --- | --- | --- |
| 剣士 | 斬りかかる（前衛） | 攻撃力ぶん（3）のダメージ。気合いの強化も乗る |
| 聖女 | 祈りの手（どこでも） | 味方1人のHPを2回復 |
| 守護騎士 | かばう（前衛・対応可） | 次の自分のターンまで、味方1人への攻撃を代わりに受ける。対応で使うと、今の攻撃（味方のヒーローへの攻撃）を代わりに受ける |
| 魔術師 | 魔弾（どこでも） | 遠距離1ダメージ。後衛からでも撃てる |
| 盗賊 | すり抜け（前衛） | 2ダメージ。このターン、もう1回移動できる |

攻撃系の固有スキル（斬りかかる・魔弾・すり抜け）には、相手が対応できる。

## 対応

- 相手が**攻撃**（通常攻撃か攻撃カード）を宣言すると、こちらは**対応カード**を1枚使える
- 対応が先に処理され、そのあと攻撃が処理される
- **対応への対応はない**（1段だけ）
- 移動や支援カードには対応できない
- **使わずに残したマナ**は、相手のターンの対応に使える。マナは次の自分のターンの始めに回復し直す
- 受付時間は**5秒**。対応できるカードがなくても、同じだけ待つ（待ち時間から手札が読まれないように）。「対応しない」で即スキップできる
- CPU が対応するかを考えるときも、約1秒待つ

### 対応カード（5枚）

| カード | ヒーロー | 位置 | 対応で使ったときの効果 |
| --- | --- | --- | --- |
| 加護【1】 | 聖女 | 後 | 味方1人に盾3。狙われた味方が初期の対象 |
| 癒しの光【1】 | 聖女 | 後 | 味方1人のHPを3回復 |
| 守りの構え【1】 | 守護騎士 | 後 | 味方1人に盾4 |
| 挑発【1】 | 守護騎士 | 前 | その攻撃（と次の自分のターンまでの攻撃）を守護騎士に引きつける |
| 足払い【1】 | 盗賊 | 前 | 攻撃してきた前衛に1ダメージを与えて後衛に下げる。前衛からの攻撃は不発になる |

対応カードは、自分のターンに普通に使うこともできる。盾と挑発は、次の自分のターンの始めまで続く。

## カード（20枚）

| ヒーロー | HP・攻撃 | カード |
| --- | --- | --- |
| 剣士 | 12・3 | 斬撃【1・前】3ダメージ／踏み込み【2・前】5ダメージ、自分も1／連撃【2・前】3ダメージを2回／気合い【1】このターンの次の攻撃+2 |
| 聖女 | 10・1 | 光の槌【1・前】2ダメージ、当たれば味方全員+1回復／癒しの光【1】対応／加護【1】対応／祈り【0】このターンのマナ+2 |
| 守護騎士 | 15・2 | 盾打ち【1・前】2ダメージ、当たれば自分に盾2／挑発【1・前】対応／鉄壁【2・前】味方全員に盾3／守りの構え【1】対応 |
| 魔術師 | 8・1 | 火炎【2・前】前衛の敵全員に3ダメージ／魔力の矢【1】遠距離2ダメージ／雷【3】遠距離5ダメージ／瞑想【0】このターンのマナ+1 |
| 盗賊 | 10・3 | 投げナイフ【1・前】遠距離2ダメージ／足払い【1・前】対応／急所突き【2・前】遠距離3ダメージ、相手のHPが半分以下なら6／盗み【1】相手のヒーローの手札を1枚、巡回の最後へ送る |

「前」は前衛用（そのヒーローが前衛にいるときだけ使える）。v0.4 で各ヒーローに1枚ずつ足した（連撃・祈り・鉄壁・雷・急所突き）。

## 同時計画制（proto6）からなくなったもの

- 素早さと、同時処理の順番のルール（行動は1つずつ順に処理される）
- 計画の予約と取り消し
- 「移動で空振りさせる」読み合い（「対応の足払いで不発にする」に置き換わった）

## CPU

- 自分のターン：できる行動を全部試し、評価が良くなる限り1つずつ行う。対応カードを持っていれば、そのコストぶんのマナを残すことにも価値を置く
- 対応：対応しない場合と、各対応を使った場合を比べ、少しでも得なら使う
- 相手の手札は見ない（ただし後衛の正体は見えている。試作のための手抜き）

## 画面

- **タイトル**：要点3つ・設定（1ターンの時間、処理の再生）・対戦ボタン。詳しいルールは「ルールを読む」の別画面
- **ヒーロー選択**：各ヒーローの固有スキルと4枚のカードを一覧で表示。最初に前衛に立つヒーローを選べる
- **対戦**（上から）
  - 相手のバー（相手のマナ。相手のターン以外では「対応用のマナ」）
  - 相手のタワー → 相手の後衛・前衛
  - **真ん中の帯**：ラウンド、「▲ あなたのターン／▼ 相手のターン」、今のフェーズと残り時間（下の縁にゲージ）。対応の受付中は青になる
  - 自分の前衛・後衛 → 自分のタワー
  - 自分のバー（マナ）
  - 手札（ヒーローごとに2枚と、次に来るカード。対応カードには「対応」、前衛用には「前衛」の札）
  - 説明欄（選んだもの、ヒーローの詳細、処理の再生中はその段階の題と「なぜ」）
  - ボタン
- 攻撃の向きを**矢印**で表示する（相手の攻撃は赤、自分は金、味方への支援は緑。対応の受付中は点線が流れる）
- 手番の側の盤面はうっすら色付けし、ターンが替わった瞬間は盤面の中央に大きく表示する

## CPU 同士のシミュレーション（v0.5、300試合）

- 平均5.7ラウンドで決着、上限まで行く試合は約4%、先攻の勝率は約54%
- 固有スキルの使用（1試合あたり）：魔術師 約2.0回、剣士 約1.9回、盗賊 約1.5回、聖女 約0.6回
- CPU は守護騎士の「かばう」を自分のターンには使わない（次の相手のターンに守る価値を先読みできないため）。対応では使う
- ヒーロー別の勝率：剣士 約70%、聖女 約54%、盗賊 約54%、魔術師 約39%、守護騎士 約33%

## CPU 同士のシミュレーション（v0.4、400試合）

- 巡回式にすると、使うたびに次のカードが入るので攻め手が途切れず、決着が早くなった（タワーHP20のままだと平均4.5ラウンド）
- タワーHPを25に上げ、最初のラウンドの後攻のマナを3にした
  - 平均5.2ラウンドで決着、上限まで行く試合は約1%
  - 先攻の勝率：補正なしで約61% → 補正ありで約55%
- ヒーロー別の勝率：剣士 約68%、聖女 約60%、盗賊 約53%、魔術師 約37%、守護騎士 約32%

## CPU 同士のシミュレーション（v0.3、250〜300試合）

v0.2 の課題：復活が後衛で前に出るのに1マナかかる／タワーの反撃が重く「前衛を倒す」が安全策になってタワーが機能しない／10ラウンドまでもつれる。

| 調整 | 平均の決着 | 上限まで | タワーへの攻撃（守られ／無防備） |
| --- | --- | --- | --- |
| v0.2 のまま | 7.9R | 33% | 4.5／6.1 回 |
| 移動0マナ | 7.5R | 28% | 4.5／6.2 回 |
| 撃破でタワー5 | 6.1R | 2% | 3.8／3.8 回 |
| 反撃は1ターン1回 | 7.2R | 21% | 7.0／5.2 回 |
| **移動0＋撃破でタワー4＋反撃1ターン1回（採用）** | **5.7R** | **5%** | **5.9／3.9 回** |

- 撃破だけだとタワーが「点数表」になり、直接殴る回数はむしろ減る。反撃を1ターン1回にして、守られたタワーを殴る判断が成り立つようにした
- 先攻の勝率 約50%
- ヒーロー別の勝率：剣士 約70%、盗賊 約57%、聖女 約47%、守護騎士 約39%、魔術師 約37%

## CPU 同士のシミュレーション（v0.2、250試合）

v0.1 の課題（攻め手が足りず、前衛を倒してもタワーを殴りきれない）への調整を比べた。

| 調整 | 上限まで行く試合 | 先攻の勝率 |
| --- | --- | --- |
| v0.1 のまま | 約41% | 約48% |
| 倒されたら自分のターンを1回休む | 約38% | 約48% |
| ＋前衛は2枚生む（**採用**） | 約28〜29% | 約48〜49% |
| ＋前衛は2枚生む＋通常攻撃0マナ | 約25% | 約51% |
| 前衛は2枚生む＋自分のターンを2回休む | 約31% | 約51% |

- 1試合あたり、対応は約2.5回
- ヒーロー別の勝率：剣士 約74%、盗賊 約70%、守護騎士 約45%、聖女 約38%、魔術師 約25%

- 1試合あたりの攻撃は約32回、対応は約3.3回。5種類の対応カードはどれも使われる（多い順に挑発・加護・癒しの光・守りの構え・足払い）
- **10ラウンドの上限まで行く試合が約40%と多い**
