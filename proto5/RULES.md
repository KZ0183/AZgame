# 五枚決闘（仮）ルール v0.3

5枚のデッキで遊ぶ、2人対戦のカードゲーム。スマホ縦画面を想定。
既存の「かな戦記」とは別の試作。ブラウザで `index.html` を開けば CPU と対戦できる。

v0.3 で、同時公開をやめて**交互のターン制**（MTG 型）にした。

## 構成

| ファイル | 内容 |
| --- | --- |
| `engine.js` | ルールエンジンと CPU。DOM に依存しない（Node でも動く） |
| `index.html` | 画面（タイトル・デッキ構築・対戦） |

## デッキ構築

- **主属性**を1つ選ぶ（赤・青）。主属性は相手に**公開**される
- **副属性**を0〜1つ選ぶ。副属性は**非公開**。副属性のカードはコスト+1
- 主属性・副属性・無色のカードから**5枚**を選ぶ。同じカードは1枚まで。中身は非公開
- 自陣の3レーン（左・中・右）に**地形**を1つずつ置く。同じ地形は1つまで。地形は試合開始時に公開される

## 試合の流れ

- ライフは各15。5枚すべてが最初から手札
- 先攻・後攻はランダム。1ラウンド＝お互いが1ターンずつ。**最大10ラウンド**
- 自分のターンの**マナ＝ラウンド数**。余っても持ち越さない
- 自分のターンにできること（どれも、行った瞬間に処理される）
  1. 手札から**1枚まで**出す
  2. 場の自分のクリーチャーの**起動能力**を使う（1体につき1ターン1回）
  3. **攻撃**する（攻撃させるクリーチャーを選ぶ）→ ターン終了
- ターンの始めに、自分のクリーチャーの「休み」と「出したて」が解ける

## クリーチャー

- **出したて**：出したターンは攻撃できない。ただし**速攻**を持つものは攻撃できる
- 自分のクリーチャーがいるレーンに新しいクリーチャーを出すと、古い方は入れ替わりで退場する
- 受けたダメージは回復しない

## 攻撃とブロック

- 攻撃したクリーチャーは**休み**になる。休んでいるクリーチャーは、**相手の次のターンにブロックできない**
- 正面（同じレーンの相手側）に、休んでいないクリーチャーがいれば**自動でブロック**され、お互いのパワー分のダメージを与え合う
- 正面にいない、または休んでいれば、相手プレイヤーにパワー分のダメージ
- **飛行**：飛行を持たないクリーチャーにはブロックされない（飛行は地上の攻撃をブロックできる）
- **貫通**：ブロックしたクリーチャーの残り体力を超えた分が、相手プレイヤーに届く

## 起動能力

- 【n】はコスト。**【n・休む】**の能力は、使うとそのクリーチャーが休みになる（そのターンは攻撃できず、次の相手のターンにブロックもできない）。出したてのターンには使えない
- 休まない能力（強化・移動）は、出したターンでも使え、使ったあとに攻撃もできる

## 勝敗

1. どちらかのライフが0以下になったら即終了
2. 10ラウンドが終わったら、ライフが多い方の勝ち
3. ライフが同じなら、盤面のクリーチャーのパワー合計が多い方の勝ち
4. それも同じなら引き分け

## 地形（7種）

| 地形 | 効果（自陣側に置く） |
| --- | --- |
| 平原 | 効果なし |
| 火山 | ここの自分の赤クリーチャーはパワー+1 |
| 霧の湖 | ここの自分の青クリーチャーが受ける戦闘ダメージ−1 |
| 城壁 | このレーンから自分が受けるダメージ−1 |
| 祭壇 | ここで自分のクリーチャーが死ぬと、自分のライフ+2 |
| 沼地 | 向かいに出た相手のクリーチャーは−1/−1 |
| 見張り塔 | ここに自分のクリーチャーを出すと、相手の手札を1枚ランダムに見る |

## CPU

- 相手の手札は見ない
- 出すカードの候補ごとに、起動能力を良くなる限り足し、攻撃するクリーチャーの組み合わせを全部試す
- 評価は「自分のターンを終えたあと、相手が全員で殴り返してきた盤面」で行う
- 用意したデッキは6つから、ランダムに選ぶ

## 現時点の課題（CPU 同士のシミュレーション、約360試合）

- 先攻の勝率は約50%で、偏りはない
- **約65%の試合が10ラウンドの上限まで続く**。どのレーンにもブロッカーがいると攻撃が損になり、盤面が膠着する（CPU が攻撃できる場面で攻撃したのは約4割）
  - 初期ライフを10にしても、上限まで続く試合は約47%
- デッキ同士の相性差が大きい
