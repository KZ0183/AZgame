# 五枚決闘（仮）ルール v0.1

5枚のデッキで遊ぶ、2人対戦のカードゲーム。1試合5分以内。スマホ縦画面を想定。
既存の「かな戦記」とは別の試作。ブラウザで `index.html` を開けば CPU と対戦できる。

## 構成

| ファイル | 内容 |
| --- | --- |
| `engine.js` | ルールエンジンと CPU。DOM に依存しない（Node でも動く） |
| `index.html` | 画面（タイトル・デッキ構築・対戦） |

## デッキ構築

- **主属性**を1つ選ぶ（赤・青）。主属性は相手に**公開**される
- **副属性**を0〜1つ選ぶ。副属性は**非公開**。副属性のカードはコスト+1
- 主属性・副属性・無色のカードから**5枚**を選ぶ。同じカードは1枚まで。中身は非公開
- 自陣の3レーン（左・中・右）に**地形**を1つずつ置く。同じ地形は1つまで。地形は試合開始時に公開される
  - 地形はデッキの手がかりにもなる（火山を置いている → 赤が多そう）

## 試合の流れ

- ライフは各10。5枚すべてが最初から手札
- ターン1〜5。**マナはターン数と同じ**で、余っても持ち越さない
- 毎ターン、2人同時に手札から1枚と、出す場所（レーン）を選んで伏せる。パスもできる
- 同時に公開して、次の順で処理する
  1. **打ち消し**（封じの言葉）。お互いに打ち消し合うこともある
  2. **呪文**（自分 → 相手の順。対象は場に出ているクリーチャーだけ）
  3. **クリーチャー登場** → 登場時効果 → 地形の効果。同時に出たクリーチャーの登場時効果は、片方が先に手札へ戻されても両方とも出る
  4. **戦闘**（全レーン同時）
- 自分のクリーチャーがいるレーンに新しいクリーチャーを出すと、古い方は入れ替わりで退場する

## 戦闘

- 各クリーチャーは毎ターン、正面に向かって攻撃する（登場したターンから攻撃する）
- 正面に相手のクリーチャーがいれば、殴り合う（ダメージは同時）。いなければ相手プレイヤーにダメージ
- **受けたダメージは回復しない**（体力が減ったまま残る）
- **飛行**：飛行同士でしか止まらない。飛行と地上が向かい合うと、お互いに素通りして相手プレイヤーを殴る
- **貫通**：正面のクリーチャーの残り体力を超えた分が、相手プレイヤーに届く

## 勝敗

1. どちらかのライフが0以下になったら終了。ライフが多い方の勝ち
2. 5ターン目が終わったら、ライフが多い方の勝ち
3. ライフが同じなら、盤面のクリーチャーのパワー合計が多い方の勝ち
4. それも同じなら引き分け

## 地形（7種）

| 地形 | 効果（自陣側に置く） |
| --- | --- |
| 平原 | 効果なし |
| 火山 | ここの自分の赤クリーチャーはパワー+1 |
| 霧の湖 | ここの自分の青クリーチャーが受ける戦闘ダメージ−1 |
| 城壁 | このレーンから自分が受けるダメージ−1 |
| 祭壇 | ここで自分のクリーチャーが死ぬと、自分のライフ+2 |
| 沼地 | 向かいに出た相手のクリーチャーは−1/−1 |
| 見張り塔 | ここに自分のクリーチャーを出すと、相手の手札を1枚ランダムに見る |

## CPU

- 相手の手札は見ない。自分の各手を「相手がパスした場合」と「相手が3/3をどこかに出した場合」で先読みし、評価が最も高い手を選ぶ
- 用意したデッキは4つ（赤単・青単・赤主体の赤青・青主体の青赤）からランダムに選ぶ

## 現時点の課題（CPU 同士のシミュレーションより）

- デッキ同士の相性差が大きい（例：青単が赤単に約85%勝つ）
- 引き分けが約15%ある。最初に決めた「引き分けは少なめ」から見ると多い
- 平均で4.4ターン目に決着する
