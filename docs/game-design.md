# かな戦記 ゲームデザイン仕様書 v0.7

> スマートフォン向けカードゲーム（リポジトリ名は AZgame のまま。旧称の名残）
> **カードを使うのはプレイヤーだけ。相手は行動表を持つ敵キャラクター。**

---

## 1. この版で何を変えたか、なぜか

v0.6 で操作は軽くなったが、行き着く先が Hearthstone だった。
**対称な対戦のカードゲームは、カードを増やし続けないとメタが固まって死ぬ。**
個人開発でその供給は不可能で、この一点だけで路線が破綻していた。

そこで構造を非対称にした。

| | 増えるもの | 1 個あたりの調整コスト |
| --- | --- | --- |
| 対称な対戦（v0.6 まで） | カード | 他の全カードとの噛み合わせを検証 |
| 非対称（v0.7） | **敵** | プレイヤーとだけ噛み合えばいい |

敵 1 体は [`data/enemies.json`](../data/enemies.json) の十数行で足せる。
**カードは 46 枚から増やさない。** 増やすのは敵だけ。

これは Slay the Spire に似ているが、同じではない。あちらは走るたびにデッキが
増えるゲームで、カードが約 350 枚ある — つまり供給量の問題を解いていない。
この版では**道中でカードは 1 枚も増えず、変わるのは相手だけ**にしてある。

### 1.1 文字をひらがなに変えた

A〜Z をやめて あ〜ん の 46 枚にした。理由は馴染みやすさだけではない。

- **五十音は 2 次元の表になっている。** アルファベットは 26 個の並びでしかなく、
  コストを割り当てるのに外部の根拠（スクラブルの文字スコア）を借りていた
- **行を種族、段をコストにできる。** 「か行は突撃」「た行は挑発」、
  「あ段は 1 マナ、お段は 5 マナ」。**文字を見た瞬間に役割とコストが読める**
- 26 → 46 枚に増えたが、絵は 1 枚も要らない

## 2. ルール

### 2.1 勝利条件

敵のライフを 0 にする。自分のライフ **30** が 0 になったら負け。
道中は敵 3 体。ライフだけを持ち越し、1 体倒すごとに 8 回復する。

### 2.2 敵は行動表をなぞる

敵はカードも手札も持たない。決まった行動表を上から順に繰り返すだけで、
**次の 1 手は戦闘中つねに画面に出ている。** 運ではなく段取りで解く相手にするため。

| 行動 | 内容 |
| --- | --- |
| 召喚 | 雑魚を呼ぶ。雑魚もひらがなカード（絵の追加コストなし） |
| 一撃 | プレイヤーに直接ダメージ。**挑発では防げない** |
| 薙ぎ払い | こちらの盤面全部にダメージ |
| 溜め | 以降の一撃の威力が上がる。溜めるほど締切が近づく |
| 回復 | 敵が自分のライフを戻す |

雑魚は毎ターン攻撃してくる。挑発がいればそちらへ、いなければプレイヤーへ。

**一撃が挑発を無視するのは意図的。** 一時は壁で受けられる仕様だったが、
実測すると挑発と絆魂を並べただけで敵の攻め手が全部消え、
時間さえかければ必ず勝つ盤面になった（守勢デッキが全敵に 97〜100%）。
一撃だけは必ず通すことで、どのデッキにも「間に合うか」という締切ができる。

### 2.3 プレイヤーの手番

1. **マナ** — 上限が 1 増え（最大 10）、全回復する。土地カードはない
2. **ドロー** — 1 枚引く。山札が尽きると疲労ダメージが 1 ずつ増えていく
3. **メイン** — カードを出す。場は 6 体まで
4. **攻撃** — ミニオンごとに 1 回、対象を選んで殴る
5. **終了** — 手札が 8 枚を超えていれば捨てる

ブロックはない。敵の挑発がいる間は、そちらを先に倒さないと本体を殴れない。
操作は「手札をタップ」「自分をタップ → 相手をタップ」の 2 つだけ。

### 2.4 戦う前にデッキを組み替える

**相手の行動表は戦う前から全部見える。** それを見てからデッキを選ぶ。

カードが 46 枚から増えない以上、遊びの幅はここにしか作れない。
「同じ駒で違う相手を解く」という、当初からやりたかった形でもある。

（現状はプリセット 3 種から選ぶだけ。デッキ編集画面は未実装）

## 3. カード

全 46 枚。**行が種族、段がコスト。**

| 行 | 役割 | パワー / タフネス |
| --- | --- | --- |
| あ行 | 素直（能力なし） | コスト / コスト |
| か行 | 突撃（出したターンから殴れる） | コスト / コスト−1 |
| さ行 | 狙撃（出たとき敵 1 体を焼く） | コスト−1 / コスト |
| た行 | 挑発（雑魚の攻撃を引き受ける） | コスト−1 / コスト+1 |
| な行 | 絆魂（与えたぶん回復） | コスト−1 / コスト |
| は行 | 貫通（壁を倒した余りが本体へ） | コスト / コスト−1 |
| ま行 | 硬いだけ | コスト−1 / コスト+2 |
| や行 | 高火力 | コスト+1 / コスト−1 |
| ら行 | ドロー | コスト−1 / コスト |
| わ行 | 回復 | コスト−1 / コスト |
| ん | 唯一の 6 コスト。7/7 貫通、デッキに 1 枚まで | |

コストは段で決まる。**あ段 1、い段 2、う段 3、え段 4、お段 5。**
段が欠けている や行・わ行（や・ゆ・よ / わ・を）だけは個別に割り当てた。

確定値は [`data/cards.json`](../data/cards.json) を参照。

## 4. バランス実測

    dart run tool/simulate.dart 500

自動プレイヤーの勝率。**縦に読んで一律に強いデッキがないこと、
横に読んで敵ごとに最適が入れ替わることを見る。**

| | 木こり人形 | 百足の群 | 鬼 |
| --- | --- | --- | --- |
| 初伝（挑発で受けて盤面を取る） | **83.6%** | 61.2% | 77.4% |
| 疾風（雑魚を無視して押し切る） | 49.6% | 0.0% | **79.2%** |
| 守勢（受け切って長期戦） | 76.8% | **97.4%** | 73.4% |

| 平均ターン数 | 木こり人形 | 百足の群 | 鬼 |
| --- | --- | --- | --- |
| 初伝 | 7.0 | 8.7 | 10.7 |
| 疾風 | 5.5 | 5.8 | 9.9 |
| 守勢 | 7.5 | 10.6 | 11.0 |

**最適デッキは 3 体とも入れ替わっている**（初伝 → 守勢 → 疾風）。
デッキを組み替える意味がある、という最低条件は満たした。

### 4.1 この表の読み方と、まだ悪いところ

**疾風 × 百足の群が 0.0%。** 相性の極端さとしては意図どおり
（並べてくる相手に、脆い速攻を持ち込んではいけない）だが、
0% は選択肢ですらない。相性差は残しつつ 15〜25% には引き上げたい。

**鬼の列が平坦（79.2 / 77.4 / 73.4）。** 3 体目だけデッキ選択がほぼ効いていない。
鬼は召喚・一撃・薙ぎ払い・溜め・回復を全部やる「万能型」なので、
どのデッキにも等しく刺さってしまっている。得意分野を絞るべき。

**全体に勝率が高い。** 最適を選べば 8 割前後で勝てる。
道中 3 連戦の通し勝率としては妥当だが、1 戦ごとの緊張感は薄い。

## 5. ここから何を調整するか

**1. デッキ編集画面。** いまはプリセット 3 種で、これがバランス実測の解像度も
制約している。46 枚から自分で 30 枚選べるようになって初めて、
このゲームの主要な選択が成立する。**最優先。**

**2. 敵を増やす。** 3 体ではボリュームとして話にならない。
この構造を選んだ理由が「敵なら安く増やせる」ことなので、
実際に 10 体以上並べて、行動表の語彙（召喚・一撃・薙ぎ払い・溜め・回復）が
足りているかを確かめる必要がある。

**3. 鬼の役割を絞る。** 万能型をやめ、たとえば「溜めて大振りする」に一本化する。

**4. 選択 UI。** 狙撃の対象はいまヒューリスティックが自動で選んでいる。

**5. フォント。** 文字が主役のゲームなのに、まだ同梱していない。
