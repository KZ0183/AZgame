# かな戦記（リポジトリ名は AZgame のまま）

スマートフォン向けカードゲーム（開発中・仮称）

あ〜ん の 46 枚でデッキを組み、行動表を持つ敵キャラクターを順に倒していく。
**カードを使うのはプレイヤーだけ。** 相手はカードを持たない。

## 現在の状態

**道中（敵 3 体）を通しで遊べる状態（v0.7）。**
v0.6 までの対称な対戦をやめた版。理由は
「対称な対戦はカードを増やし続けないと死ぬが、個人開発でその供給は無理」。
増やすのは敵だけにして、カードは 46 枚で固定した。
詳しくは [`docs/game-design.md`](docs/game-design.md) を参照。

## 構成

| パス | 内容 |
| --- | --- |
| `lib/src/engine/` | ルールエンジン。Flutter に依存しない純粋 Dart |
| `lib/src/ui/` | 画面。タイトル・道中・戦闘・図鑑 |
| `lib/src/data/*.g.dart` | `data/*.json` から生成される（直接編集しない） |
| `tool/generate_catalog.dart` | カタログ生成。`data/*.json` を編集したら実行する |
| `tool/simulate.dart` | 自動プレイヤーを回してデッキ × 敵の勝率表を出す |
| `test/` | エンジンと UI のテスト |

## ルール概要

- **行が種族、段がコスト。** か行は突撃、た行は挑発。あ段 1 マナ、お段 5 マナ
- **マナは自動。** 毎ターン上限が 1 増え（最大 10）、全回復する。土地カードはない
- **敵の次の一手は常に見えている。** 運ではなく段取りで解く
- **ブロックはない。** 攻撃側が対象を選ぶ。ただし敵の挑発は先に倒す必要がある
- **敵の本体の一撃は挑発では防げない。** これがどのデッキにも共通の締切になる
- **戦う前に敵の行動表を見てデッキを選べる。** ここが遊びの中心
- 道中は敵 3 体。ライフだけ持ち越し、1 体倒すごとに 8 回復

## 開発

```sh
flutter run                           # 実行
flutter test                          # テスト
dart run tool/generate_catalog.dart   # data/*.json を編集したら再生成
dart run tool/simulate.dart 500       # バランス実測（デッキ × 敵の勝率表）
```

敵を 1 体足すには [`data/enemies.json`](data/enemies.json) に十数行を書いて
再生成するだけでよい。カードと違い、他のカードとの噛み合わせを検証する必要がない。

## 既知の制約

- **デッキ編集画面がない。** プリセット 3 種から選ぶだけ。最優先の宿題
- 敵が 3 体しかいない。この構造を選んだ理由からして、まず数を出す必要がある
- 狙撃の対象はヒューリスティックが自動で選ぶ。選択 UI は未実装
- 文字が主役のゲームなのに、フォントを同梱していない
- リポジトリ名とアプリ名がずれている（旧称 AZgame の名残）
