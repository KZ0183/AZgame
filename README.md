# AZgame

スマートフォン向け デッキ構築型カードゲーム（開発中・仮称）

A〜Z の 26 種の文字カードでデッキを組み、盤面に文字を並べて「単語」を完成させ、
相手のライフを削り切る対戦カードゲーム。

## 現在の状態

**AI 対戦が遊べる状態（v0.4 / 完全情報の盤面ゲーム）。**
運の要素は一切なく、両者が同じ 26 文字を持って 5×5 の盤を取り合う。

## 構成

| パス | 内容 |
| --- | --- |
| `lib/src/engine/` | ルールエンジン。Flutter に依存しない純粋 Dart |
| `lib/src/ui/` | 画面。タイトル・対戦・図鑑 |
| `lib/src/data/catalog.g.dart` | `data/*.json` から生成されるカタログ（直接編集しない） |
| `tool/generate_catalog.dart` | カタログ生成。`data/*.json` を編集したら実行する |
| `tool/simulate.dart` | AI 同士の対戦を大量に回してバランスを実測する |
| `test/` | エンジンのテスト |

## ルール概要

- 両者が **A〜Z を 1 枚ずつ**持ち、交互に **5×5 の盤**へ置く。持ち駒はすべて公開
- 縦か横に**自分の駒だけ**で登録単語か連番が並ぶと成立
- 成立した**文字数と同じ枚数だけ**、隣接する相手の駒を奪える
- 奪った駒は**自分の持ち駒**になる。同じ文字が両者の間を行き来する
- 24 手を終えた時点で、**盤上の駒が多い方の勝ち**

デッキもドローもマナもない。負けたら読みが足りなかっただけ。

## 開発

```sh
flutter run                           # 実行
flutter test                          # テスト
dart run tool/generate_catalog.dart   # data/*.json を編集したら再生成
dart run tool/simulate.dart 500       # バランス実測
```

## 既知の制約

- 選択を伴う効果（`KEY` のデッキサーチ、`FOX` のハンデス、`I` の上 3 枚確認）は、
  プレイヤー側もヒューリスティックが自動で選ぶ。選択 UI は未実装
- デッキ編集画面がない。プリセット 2 種から選ぶだけ
- 文字を主役にしたゲームなのに、フォントを同梱していない
