# AZgame

スマートフォン向け デッキ構築型カードゲーム（開発中・仮称）

A〜Z の 26 種の文字カードでデッキを組み、盤面に文字を並べて「単語」を完成させ、
相手のライフを削り切る対戦カードゲーム。

## 現在の状態

**AI 対戦が遊べる状態（v0.3 / MTG ベースに全面改訂）。**
タイトル → デッキ選択 → 対戦 → 決着まで一通り動く。
ルールはテスト 69 件で検証済み。バランスは AI 同士の対戦を数百回まわして実測している。

## ルール概要

- 2 人対戦。相手 LP 60 を 0 にすれば勝ち。目安 8〜12 ターン / 3〜5 分
- **文字はパーマネント。** 戦場に出た文字は残り続け、毎ターン攻撃し、能力を発揮する
- **母音はマナ源。** A E I O U はコスト 0 で 1 ターン 1 枚だけ出せ、毎ターンエナジーを生む。
  MTG の土地に相当し、デッキの母音枚数が土地枚数の調整にあたる
- **戦場は 5 レーン。** 自分のレーン i は相手のレーン i と対峙し、戦闘は自動で解決する。
  相手が空けているレーンなら本体にダメージが通る
- **単語は陣形。** 並んだ文字が登録ワードと一致すると、**文字を消費せずに**継続効果が乗る。
  相手は陣形を崩しに来る
- デッキは 30 枚。同一文字の投入上限は文字の希少性で決まる（`E` は 4 枚、`Q` は 1 枚）

詳細は[ゲームデザイン仕様書](docs/game-design.md)を参照。

## 開発

```sh
flutter run                           # 実行
flutter test                          # テスト
dart run tool/generate_catalog.dart   # data/*.json を編集したら再生成
dart run tool/simulate.dart 500       # バランス実測
```

## 既知の制約

- 選択を伴う効果（`KEY` のデッキサーチ、`FOX` のハンデス、`I` の上 3 枚確認）は、
  プレイヤー側もヒューリスティックが自動で選ぶ。選択 UI は未実装
- デッキ編集画面がない。プリセット 2 種から選ぶだけ
- 文字を主役にしたゲームなのに、フォントを同梱していない

## 次の検討事項

- アートスタイル
- プリセットデッキの拡充（現在 2 種でバランス実測の精度を制約している）
