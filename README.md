# AZgame

スマートフォン向け デッキ構築型カードゲーム（開発中・仮称）

A〜Z の 26 種の文字カードでデッキを組み、盤面に文字を並べて「単語」を完成させ、
相手のライフを削り切る対戦カードゲーム。

## 現在の状態

**AI 対戦が遊べる状態。** タイトル → デッキ選択 → 対戦 → 決着まで一通り動く。
判定ロジックはテスト 76 件で検証済み。バランスは AI 同士の対戦を数百回
まわして実測している。

## ルール概要

- 2 人対戦。相手 LP 80 を 0 にすれば勝ち。目安 8〜12 ターン / 3〜5 分
- デッキは 30 枚。同一文字の投入上限は文字の希少性で決まる（`E` は 4 枚、`Q` は 1 枚）
- 各プレイヤーは 5 マスの**スペルライン**を持ち、任意のマスに 1 ターン 2 枚まで配置できる
  （埋まっているマスは上書きになり、元のカードは墓地へ）
- ターン終了時に判定
  - **シークエンス** — 隣接するカードが昇順に並んでいるとダメージ。連番ならボーナス増。
    そのターン置いたカードを含む並びだけが発動する
  - **ワード** — 隙間なく並んだ文字が登録済みコンボワードと一致すると、大技が発動
- カードのコストとパワーはスクラブルの文字スコアに基づく。母音は安く弱い潤滑油、
  `J` `Q` `X` `Z` は重いが単体で試合を動かす切り札

詳細は[ゲームデザイン仕様書](docs/game-design.md)を参照。

## 開発

```sh
flutter run                           # 実行
flutter test                          # テスト
dart run tool/generate_catalog.dart   # data/*.json を編集したら再生成
dart run tool/simulate.dart 500       # バランス実測
```

## 既知の制約

- 選択を伴う効果（`KEY` のデッキサーチ、`FOX` のハンデス、`I` の上 3 枚確認）は、
  プレイヤー側もヒューリスティックが自動で選ぶ。選択 UI は未実装
- デッキ編集画面がない。プリセット 2 種から選ぶだけ
- 文字を主役にしたゲームなのに、フォントを同梱していない
