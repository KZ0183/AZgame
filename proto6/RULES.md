# ふたりの英雄（仮）ルール v0.2

2人のヒーローを前衛・後衛に立たせて戦う、2人対戦のカードゲーム。スマホ縦画面を想定。
`proto5`（五枚決闘）の議論から方向を変えた試作。ブラウザで `index.html` を開けば CPU と対戦できる。

## 考え方

- デッキ構築は**ヒーローを2人選ぶだけ**。カードはヒーローが生み出す
- 各ヒーローは固有のカードを**5枚**持つ（Lv1で3枚、Lv2で1枚、Lv3で覚醒カード1枚が解放される）
- 育成は**対戦中だけ**。試合をまたぐ育成は、見た目などの強さに関わらないやり込み要素にする（未実装）
- レベルアップは**マナで買う**。カードを使うか、ヒーローを育てるかでマナを取り合う（v0.2）
- 勝敗は**ノックアウト制**。削るだけでは勝てず、倒し切る力が要る

## 構成

| ファイル | 内容 |
| --- | --- |
| `engine.js` | ルールエンジンと CPU。DOM に依存しない（Node でも動く） |
| `index.html` | 画面（タイトル・ヒーロー選択・対戦） |

## 陣形

- ヒーローは**前衛**か**後衛**に立つ。最初にどちらを前衛にするかは選べる
- **前衛**：通常攻撃と前衛用のカードが使える。相手の攻撃を受ける
- **後衛**：通常攻撃はできない。遠距離の技しか受けない
  - ただし前衛が1人もいなければ、普通の攻撃も後衛に届く（ダメージ−1）
- 前衛2人（攻め）・前後（標準）・後衛2人（守り）の陣形は、このルールから自然に生まれる
- 位置の入れ替えは1マナ。1人につき1ターン1回

## ターン

- 先攻・後攻はランダム。1ラウンド＝お互いが1ターンずつ。最大12ラウンド
- 自分のターンの**マナ＝ラウンド数+1**（上限6）。先攻の最初のターンだけマナ1
- ターンの始めに
  1. 倒れていたヒーローが**後衛で全快復活**する（Lv1に戻る）
  2. 自分のヒーローの盾・挑発・不屈が切れる
  3. 各ヒーローが、**今いる位置に合ったカードを1枚生む**（前衛なら前衛用、後衛なら後衛用。解放済みのものからランダム）。手札は最大5枚で、溢れた分は消える
- 自分のターンにできること（何回でも、マナが続く限り）
  - カードを使う。**前衛用のカードは、そのヒーローが前衛にいるときだけ使える**
  - 前衛のヒーローで**通常攻撃**（1マナ・1人1ターン1回・攻撃力ぶんのダメージ）
  - 位置の入れ替え（1マナ）
  - **レベルアップ**（ヒーローごとのコスト）

## 成長

- 自分のターン中いつでも、マナを払ってヒーローを1段階上げられる（Lv3まで）
- **コストはヒーローごとに違う**。これが育ち方の個性になる
- 上がった瞬間に、新しく解放されたカードを1枚手札に得る。このカードだけは手札の上限（5枚）を超えても受け取れる
- 手札が5枚以上のときは、ターン開始時のカードの生成は止まる
- レベルを上げたターンも、そのヒーローは普通に行動できる
- 倒されるとLv1に戻る。高いマナをかけたヒーローほど、守る価値が上がる

## 勝敗

- 盾があれば、先に盾がダメージを受ける
- 相手のヒーローを倒すと**1点**。**3点先取**で勝ち
- 倒されたヒーローのカードは手札から消える
- 12ラウンドで決まらなければ、点数 → 残りHPの合計で判定

## 非公開の要素

- 相手の後衛ヒーローは、前衛に出るか、カードを使うか、ダメージを受けるまで「？？？」と表示される
- 相手の手札は枚数だけ見える

## CPU

- 今できる行動を全部試し、評価が良くなる限り行動を重ねる
- 評価：点数、HP・盾・レベル、次の相手のターンに倒されそうな前衛の危険度、手札が溢れそうかどうか
- 相手の後衛の正体や手札も見えている（試作のための手抜き）
- 用意した二人組は5組から、ランダムに選ぶ

## CPU 同士のシミュレーション（v0.2、約500試合）

- 決着は7〜12ラウンド目が中心。12ラウンドの上限まで行くのは約19%（v0.1 は約6%）。マナがレベルアップに回るぶん、攻撃が遅くなった
- 先攻の勝率は約52%
- レベルアップに使われたマナは全体の約31%。「序盤はレベル上げ一択」にはなっていない
- Lv2に上げる平均ラウンドは、剣士4.5 〜 魔術師5.8。コストの差が育ち方の差として出ている
- 試合終了時点で、ヒーローの約90%がLv2、約48%がLv3（覚醒）
- **ヒーロー別の勝率に差が大きい**：剣士 約67%、聖女 約69%、魔術師 約43%、盗賊 約39%、守護騎士 約31%
- 「使えるカードを全部使って殴るだけ」の単純な自動操作に、CPU は約91%勝つ（v0.1 は約75%）
