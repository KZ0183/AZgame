# ふたりの英雄 連戦版（proto9）

proto8（1戦だけの PvE）に、**3連戦と報酬**を足した試作。戦闘のルールは proto8 と同じ（`../proto8/RULES.md`）。

## 冒険の流れ

ヒーロー2人を選ぶ → 第1戦 → 報酬 → 第2戦 → 報酬 → ボス戦

- 第1戦・第2戦は、普通の敵3体からランダムに2体（HPは22・26）
- **ライフは持ち越し**。ヒーローのHPは戦闘ごとに全快
- 前衛・後衛の並びは、前の戦闘の終わりの並びを引き継ぐ

## 報酬（3つから1つ）

カードの**枚数は増やさない**（各ヒーロー4枚のまま）。5枚前後で戦う手軽さを残すため。

- **新しいカード**：片方のヒーローの新カード1枚と、今のカード1枚を入れ替える
- **強化**：もう片方のヒーローの固有スキル強化（強化済みなら最大HP+3）
- **回復**：ライフ+6

## ボス：黄昏の魔王（HP32）

- 通常：前衛へ5 → 後衛へ5 → 溜め3 → 強打7 → 身を固める5
- **HPが半分を切ると本気**：全体4 → 溜め4 → 強打8 → 後衛へ6（予告の巡回が最初からに変わる）

## proto8 からの調整

- 剣士が強すぎた（剣士を前衛にすると第1戦が3ラウンドで終わる）
  - 固有スキル「斬りかかる」3 → 2ダメージ
  - 「連撃」3ダメージ×2 → 2ダメージ×2
- 怒りは「予告を一巡するたびに+3」のまま。ボスが本気になると巡回が変わるので、一巡の数え方を回数で持つようにした

## シミュレーション（全20組×5回、CPU が戦い、報酬は適当に選ぶ）

- クリア率 約66%（調整中、40〜66%でぶれる）
- 1戦あたり平均7〜8ラウンド
- 負けた場所：第1戦・第2戦・ボスでほぼ均等

## 分かっている課題

- CPU は「後衛の剣士を前に出す」のような、効果が次のターン以降に出る手を選べない。守護騎士を前衛・剣士を後衛で始めると、戦闘が11〜20ラウンドかかる。人が遊べば問題ないが、初期の並びは剣士を前衛にした
- ヒーローの強さの差はまだ大きい（剣士が強い）
- 報酬の選択肢が毎回3つ固定の形。分かれ道のマップはまだない
