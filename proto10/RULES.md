# ふたりの英雄 仕様（proto10）

1ステージ（3連戦）を仕上げた版。合格基準とレビューの記録は `REVIEW.md`、計測の道具は `tools/`。
ヒーロー・カード・敵の表は `node tools/spec.js` でエンジンから出したもの（手で書き換えない）。

## 概要

- 1人用。ヒーロー2人を前衛・後衛に置き、**次の行動を予告する敵**と戦う
- スマホ縦画面。1ステージ（3連戦）で10〜15分
- デッキ構築は**ヒーローを2人選ぶだけ**。各ヒーローが4枚のカードを持つ

## 勝ち負け

- 敵のHPを0にしたら、その戦闘に勝つ。3戦すべてに勝てば踏破
- あなたのライフ（20）が0になったら負け。冒険はそこで終わる
- ヒーローのHPが0になると倒れ、ライフが4減る。倒れたヒーローは次の自分のターンを休み、その次のターンに後衛でHP全快で復活する（もう1人も後衛にいると前衛が空になる）

## 冒険（1ステージ）

ヒーロー2人と最初の並びを選ぶ → 第1戦 → 報酬 → 第2戦 → 報酬 → ボス戦

- 第1戦・第2戦の敵は、普通の敵3体からランダムに2体（HPは第1戦36、第2戦46）
- ライフは持ち越す。ヒーローのHPは戦闘ごとに全快
- どの戦闘も、前衛1人・後衛1人の並びで始まる（戦闘の前に入れ替えられる）
- 報酬は3つから1つ
  - **新しいカード**：片方のヒーローの新カード1枚と、今のカード1枚を入れ替える（4枚のまま）
  - **固有スキルの強化**：もう片方のヒーロー。強化済みなら最大HP+3
  - **最大HP+3**：新カードと同じ側のヒーロー
- 報酬の候補は、その回のうちは変わらない（選び直しても同じ3つ）
- ライフを回復する手段はない（ライフは倒れたときに4ずつ減るので、少しの回復でも「もう1回倒れてよい」になり、常に正解の報酬になってしまうため）

## 敵の予告

敵は次の行動を予告している。予告は決まった順番で巡回し、「ターン終了」で予告どおりに動く。

| 予告 | 当たり先 |
| --- | --- |
| 前衛へ攻撃 | 前衛の全員。前衛に誰もいなければライフ |
| 後衛へ攻撃 | 後衛の全員。後衛に誰もいなければライフ |
| 強打 | 前衛のうち今のHPが高いほう1人（同じなら左）。挑発しているヒーローがいれば、位置に関係なくそちら。前衛に誰もいなければライフ |
| 全体攻撃 | 立っているヒーロー全員。誰も立っていなければライフ |
| 溜め | 次の攻撃のダメージが増える |
| 身を固める | 敵に盾が付く。敵の次の行動が始まるときに消える |

倒れているヒーローは、その列にいないものとして扱う。毒のダメージは、敵が行動したあとに入る。

- **怒り**：敵は5回行動するたびに怒り、以後の攻撃のダメージが3ずつ増える（盗賊の「撹乱」で予告を飛ばしても、怒りは早まらない）
- **ボスの本気**：HPが半分以下になると、予告の巡回が別のものに変わって最初から始まる。溜めていたぶんは消える。怒り・毒・弱体はそのまま続く

## 自分のターン

- マナ：毎ターン3。持ち越さない。増やす手段はない
- カード、固有スキル（1マナ・1人1ターン1回）、移動（無料・1人1ターン1回）を、好きな順に1つずつ使う
- 移動は前衛と後衛を行き来すること。2人が同じ列に並んでもよい
- 「ターン終了」で敵が動く。マナが0で、使える0マナのカードも移動も残っていなければ、自動でターンが終わる
- 「前衛」の付いたカードとスキルは、そのヒーローが前衛にいるときだけ使える
- 倒れているヒーローのカードとスキルは使えない。倒れているヒーローには回復も盾も使えない
- 「味方」には自分も含む（かばうだけは自分以外）

## 守る

- **盾**：ダメージを盾の数だけ防ぐ。重ねると合計される。次の自分のターンが来ると消える
- **挑発**：次の自分のターンまで、敵の強打がそのヒーローに向く
- **反撃**：次の自分のターンまで、敵の攻撃を受けるたびに敵にダメージ。盾で全部防いでも、ダメージが0でも反撃する。その攻撃で倒れたら反撃しない。反撃で敵が倒れたら、残りの攻撃は当たらない。反撃を重ねると合計される
- **かばう**：次の自分のターンまで、味方1人が受けるはずの攻撃を代わりに受ける。自分も同じ攻撃の対象なら、先に自分のぶん、次に味方のぶんと2回受ける。途中で自分が倒れたら、残りは元の味方に当たる
- **弱体**：敵の次の攻撃1回のダメージを減らす。溜めや身を固めるをはさんでも残り、重ねると合計される
- 挑発・反撃・かばうは、使ったあとに後衛へ下がっても続く

## カードの巡回

- 各ヒーローは4枚を決まった順番で巡回させる。手札は各ヒーロー2枚。順番は戦闘ごとにランダム
- 使ったカードは順番の最後へ回り、同じ場所に次のカードが入る。次に来るカードは見えている
